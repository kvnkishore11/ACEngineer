💡 The trade-off trifecta is performance, speed, cost. This new plan template spends speed and tokens to win on performance. We're not optimizing for cheap. We scale our compute to scale our impact.

🔥 What we build into the new /plan F3 (PLANS For Fable 5) skill:
• HTML-first plan output — give your agent more useful tokens, easier for you, your team, and your AI agents to consume
• Embedded GPT Image 2 generation — one focused image per phase so a plan is worth a thousand words
• A toggleable questions-and-answers section — step into the loop only when the work is intense enough
• Rich, updatable header metadata — created, modified, commits, agent name, session id, forward and back references
• Per-phase and per-task breakdowns with an embedded checklist your agents update live
• Validation and testing sections with closed loops that block completion until every box is checked
• Dedicated workflows — create plan, update plan, update references, build plan, and image generation, all in one unified skill
