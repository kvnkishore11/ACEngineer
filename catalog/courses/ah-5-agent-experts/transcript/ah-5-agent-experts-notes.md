# Agent Experts: Finally, Agents That Actually Learn
**Lesson #13 (Advanced)**  ·  https://agenticengineer.com/tactical-agentic-coding/course/agent-experts

_The massive problem with agents is they forget - and that means they don't learn. Agent Experts solve this with a three-step workflow: Act, Learn, Reuse._

## Loot Box — 12 notes

### 🔥 The Massive Problem: Agents Forget
Traditional software improves as it's used, storing analytics and patterns. Agents of today don't - they forget everything between sessions. This is the problem Agent Experts solve.

### 🏆 The Act-Learn-Reuse Pattern
Transform forgetful agents into learning machines: Act (take useful actions), Learn (store new information), Reuse (apply expertise on next execution). No human in the loop required.

### 🔥 Mental Models: The Data Structure of Expertise
A mental model is a data structure that evolves over time. With each useful action, experts accumulate information, examples, and expertise around specific topics. This is how real experts work.

### 🔥 Self-Improving Template Meta Prompts
An Agent Expert is a concrete form of a self-improving template meta prompt. Prompts that build other prompts, with specific structure, that update themselves with new information for the next execution.

### 🔥 Meta Agentics: Build The System That Builds
Meta prompts, meta agents, meta skills - these help you build your agentic layer faster. Every codebase must have meta agentics. Prompts writing prompts, agents building agents, skills building skills.

### 🔥 Expertise Files: External Mental Models
Expertise files are isolated markdown files that store your agent's accumulated knowledge. Unlike memory files, they're topic-specific and updated by the self-improve prompt, not manually.

### 💎 Never Update Expertise Files Directly
The key insight: don't update expertise files manually. Teach your agents HOW to learn by updating the self-improve prompt. Let agents maintain their own expertise over time.

### 🔥 Codebase Experts for High-Risk Systems
Deploy codebase experts for critical areas: billing systems, security modules, database operations. These agents accumulate domain knowledge and reduce errors in high-complexity, high-risk code.

### 🔥 Product-Focused Agent Experts
Beyond code, agent experts can power adaptive user experiences. Product experts learn user patterns and preferences, creating intelligent systems that improve with usage.

### 🏆 Tactic: Build Agents That Learn
The full tactic: Create self-improving template meta prompts with expertise files. Let agents Act, Learn, and Reuse knowledge autonomously. Transform forgetful agents into domain experts.

### 🏆 When to Build Agent Experts
Build experts when: high complexity requires accumulated knowledge, error rates need reduction over time, domain-specific patterns emerge. Generic agents suffice for simple, stateless tasks.
