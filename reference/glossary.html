Reference · visual-plan nomenclature

Glossary

The vocabulary of the /visual-plan skill. Each term tagged by which layer owns it — the editable local prompt, or the remote MCP engine you don't control.

LOCAL — editable files on your disk REMOTE — owned by plan.agent-native.com
SKILL.md
local  The 460-line policy document. Pure instructions to the agent: when to gate, which mode, which remote tool to call, the quality bars. The skill's brain, not its hands.
reference core
local  On-demand quality bars (wireframe.md, canvas.md, document-quality.md, exemplar.md). Loaded only when the agent is about to author that thing — progressive disclosure.
SHARED-CORE
local  HTML-comment markers (<!-- SHARED-CORE:... START -->) marking blocks synced word-for-word with /visual-recap. Edit inside them and skills update may clobber it.
agent-native-skill.json
local  Manifest. Binds skill → remote mcpUrl, stores a contentHash, and the updateCommand. The tether to upstream.
Plan MCP connector
remote  The hosted server (plan / legacy agent-native-plans) that registers every real tool. If it loads zero tools, it didn't finish connecting — reconnect, don't fall back to inline.
block / block catalog
remote  The typed content units (diagram, data-model, api-endpoint, diff, file-tree, code, annotated-code, callout, columns, question-form…). Authoritative list comes from get-plan-blocks — never memorized.
canvas
remote  The top visual surface holding static UI mockups. Source of truth for screens under discussion. Lives in content.canvas.
artboard
remote  One frame on the canvas. Its surface preset (browser / desktop / mobile / popover / panel) locks footprint & aspect — you never set width/height.
wireframe
remote  The HTML mockup inside an artboard. You write plain semantic HTML + --wf-* tokens; the renderer owns theme, font, and the rough.js sketch overlay.
prototype
remote  The functional, clickable version of the same flow (content.prototype). Canvas = inspectable static; prototype = operable.
annotation
remote  Plain-text designer note anchored to a frame by targetId + placement. Never a bordered card; never a box around a frame.
mode
remote  Which create-tool runs: create-visual-plan (doc-first), create-ui-plan, create-prototype-plan, create-plan-design, create-visual-questions.
anchor
remote  Where a comment points. Frames: document %, element %, board pixels, or wireframe targetNodeId/targetNodePath. Read before acting on feedback.
resolutionTarget
remote  The ONLY routing signal on a comment: act on agent, treat human as context. @mentions never route.
local-files mode
local  Privacy path. AGENT_NATIVE_PLANS_MODE=local-files → write plans/<slug>/*.mdx, preview locally, zero DB writes. Keeps the engine, drops the hosting.
MDX folder
local  The portable source form of a plan: plan.mdx + optional canvas.mdx / prototype.mdx + .plan-state.json. Git-friendly.
