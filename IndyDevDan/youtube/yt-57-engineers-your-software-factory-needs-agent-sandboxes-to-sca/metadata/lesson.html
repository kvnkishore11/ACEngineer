Stop renting your machine to your agents. Give every agent its own computer. N agents, N environments, zero collisions. That's what an agent sandbox unlocks: isolation, scale, autonomy.

🚀 In this video we put the entire software factory INSIDE an agent sandbox. Not one agent in the cloud, the whole factory: the AI developer workflow, the agent configs, the app, and an orchestrator agent, all living on a machine that isn't yours. One prompt from Claude Code fires off five sandboxes on exe.dev, each running the full software developer life cycle against the same prompt. Best of N, five futures, one pick.

🛠️ The three tier architecture is the unlock. An out-loop orchestrator on YOUR machine, an in-sandbox orchestrator on each VM, and the Pi coding agent ADWs running the actual plan, build, test, review, document cycle inside the factory. Your top level agent kicks the work off and then goes quiet. That's the point. You show up at the beginning and the end, the planning and the reviewing, and nowhere in between.

🔐 Disposable keys, bounded blast radius. Every sandbox gets a freshly minted OpenRouter provisioning key with a hard spend cap at mount, and that key gets revoked at teardown. The agent can do anything it wants. What it can't do is touch your AWS, your prod, or your wallet. The blast radius IS the box.

👀 Out-loop does NOT mean blind. Every sandbox exposes ports, so you get a live URL for the running app AND a private URL for the factory observability view. Watch the gate checks, the token spend, the agent harness config, the failures. You can SSH straight into any box mid-run and talk to the orchestrator that's already working. Measure it, or you can't improve it.

🧠 Key takeaways for the agentic engineer:

Isolation, Scale, Autonomy: a container gets you isolation only. A sandbox gets you all three, and autonomy is the one that actually moves the needle.

Model Stack, Not Model: we ran five agent configs (frontier, open weights, top speed, and an all DeepSeek V4 Flash build) against one prompt. Combine compute, don't select compute.

Mount, Run, Teardown: two scripts. Setup plus health check, then execute. Ephemeral by default, rebootable on demand. That system is the real asset, not the demo app.

Best of N: one prompt, five software factories, five versions of the product. Pick the winner and move on. You also harvest cost and quality data on every config for free.

Agents Plus Code: the software factory is deterministic code wrapped around non-deterministic agents. That's what separates agentic engineering from vibe coding.

💡 Vibe coding is not knowing what your system does and not looking. Agentic engineering is knowing what your system does so well you don't have to look. The next leap of leverage is going to take real upfront work, because all the easy leverage has already been sucked up. Everyone has a terminal agent now. Almost nobody has a factory in a box.

🌟 We're entering an age of abundant compute. Cheap workhorse models are eating work you're still doing by hand. Act like a function: take the inputs, execute, synthesize, deliver. Scale your compute to scale your impact.

Stay focused and keep building.
