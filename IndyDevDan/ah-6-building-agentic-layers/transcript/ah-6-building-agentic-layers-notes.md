## Loot Box — 16 notes

### 🏆 The Codebase Singularity
The moment when you realize your agents can run your codebase better than you or your team. The moment when you trust them to ship more than you trust yourself. This is the Codebase Singularity.

### 💎 The Agentic Layer: New Ring Around Your Codebase
The agentic layer wraps around your application layer. This is where you teach agents to operate your codebase on your behalf - as well or better than you ever could.

### 🔥 Class 1 Grade 1: Prime Prompts & Memory Files
The thinnest possible agentic layer. A prime prompt and/or memory files. If you have this, you technically have an agentic layer. The foundation everything else builds upon.

### 🔥 Class 1 Grade 2: Sub-Agents, Plans & AI Docs
Specialized prompts for planning work, sub-agents you can run, and AI documentation directories. Start incrementally improving what your codebase can do with parallelizable workflows.

### 🔥 Class 1 Grade 3: Skills, MCPs & Custom Tools
Skills, MCP servers, and prime prompts with tool access. All three give the same thing - custom tools that enhance your agent's Core Four. You can bypass MCPs with well-crafted prompts.

### 🔥 Class 1 Grade 4: Closed-Loop Prompts
Request, Validate, Resolve. Agents review their own work and self-correct. More compute equals more trust, not less. If it's less, you're doing something wrong.

### 🔥 Class 1 Grade 5: Bug, Feature, Chore Templates
Templates with specific output formats for different work types. Teach agents to build like YOU do. Bug templates differ from feature templates - each encodes your engineering best practices.

### 🔥 Class 1 Grade 6: Prompt Chains & Agentic Workflows
One prompt references many prompts and/or sub-agents. Plan then build. Scout then plan. Chain composable primitives together. This is where prompt chaining becomes truly powerful.

### 🔥 Class 1 Grade 7: Agent Experts with Mental Models
Agents keeping track of mental models for specific areas of your codebase. Signs of agents running the codebase better than you emerge. Zero-touch engineering becomes reality.

### 🏆 Class 2 Grade 1: Out-Loop Systems & Webhooks
Webhooks, external triggers, the PITER framework. Your agents operate your codebase without you. HTTP endpoints that fire prompts from Slack, Jira, GitHub - anywhere. Stay out the loop.

### 💎 Class 2 Grade 2: AI Developer Workflows
Deterministic code + non-deterministic agents. Full control between each step: logging, validation, retries. The highest leverage point of agentic coding gives you the best of both worlds.

### 🏆 Class 3 Grade 1: The Orchestrator Agent
One agent to rule them all. CRUD, command, and manage other agents. Centralized control over your entire agentic layer. The orchestrator is a custom agent that acts as lead engineer.

### 💎 Class 3 Grade 2: Orchestrator Developer Workflows
Use your orchestrator to conduct entire workflows. Multi-level conversations across multiple teams of agents. Spin up teams focused on multiple problems in parallel.

### 🏆 Class 3 Grade 3: ADWs with Orchestrator
The final level. Your orchestrator runs AI Developer Workflows - deterministic code orchestrating non-deterministic agents. High trust through observability, validation, and control.
