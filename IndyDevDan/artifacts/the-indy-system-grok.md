# The Indy System · grok

Two toolkits. One brain.

## Toolkit A — Code (CPBPP)
Done-when → Classify → Leverage → Plan → Build → Prove → Capture → Promote  
Classes: chore · bug · feature · patch

## Toolkit B — Multi-agent (Pi)
| Job | Method |
|-----|--------|
| Hard decision | CEO + Board (brief → memo) |
| Multi-domain code | Lead teams (orch → leads → workers) |
| Product at N scale | UI agents (till-done + parallel) |
| Review bottleneck | Builder + Verifier (atomic claims) |

## Chooser
- Ticket / bug / feature → CPBPP  
- Strategy / uncertainty → CEO  
- Big multi-domain ship → Lead  
- Infinite variants / product ops → UI  
- “Did it really?” → Verifier  

## Trust ladder
1 CPBPP → 2 closed loops → 3 Verifier → 4 Lead → 5 CEO → 6 UI → 7 Factory → 8 ZTE (earned)

## Laws
Own harness · 1·1·1 · force conflict · thinkers≠doers · domain lock in code · flat input · AND not OR · observe everything
