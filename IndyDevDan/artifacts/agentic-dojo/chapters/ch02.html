The Idea — Systems That Build Systems

"Engineering was never about writing code. It's about building systems of leverage that produce valuable outcomes for your users and your customers."

Phase one was AI coding — the birth of the VibeCoders and "the complete commoditization of code." Phase two is agentic coding. Tactic #1 is blunt: "Your hands and your mind are no longer the best tool for the job of writing code. Full stop."

AI coding runs on the Big Three: context, model, prompt. Agentic coding adds a fourth dimension — tools — to form the Core Four. "Agentic Coding is a superset of AI coding": the new capability is "prompts that can reliably execute long chains of tools."

The Core Four. "With the right context, model, prompt, and now tools, these prompts are now more capable than ever before."

We move up the stack once again. We become a commander of compute.

— the phase-two role

The agentic prompt is a prompt containing a sequence of tool calls. As a commander of compute, "you take this compute and you use it to build systems that build systems." Your engineering cycles move to "planning, reviewing, and creating closed loop structures."

The mission of TAC: "transform you into an engineer they can't replace. You know who they are. It's your boss. It's the company. It's the industry. It's AI." And a tease of where it ends — ADWs: "long running end-to-end AI developer workflows that run for minutes to hours with and without your oversight."

4

The Workout

GOAL Feel the difference between an AI coding prompt and an agentic prompt, then run an agent programmatically.
PREREQUISITES Claude Code installed and authenticated · git · Python + uv (or Bun) · any empty repo.

To become an irreplaceable engineer, you will replace yourself.

— the contradicting truth · quote of the lesson

  1. Set the AI coding baseline

    In a fresh repo, run claude and prompt: "Create hello.py that prints 'goodbye AI coding'. Do nothing else."

  2. Now go agentic

    Prompt: "Check out a new branch demo-agentic. Create main_tac.py printing 'hello agentic coding world' and a one-line description of AI agents. Run hello.py and main_tac.py and show outputs. git add and commit with a clear message. Report all work done as a checklist."

  3. Inspect the evidence

    Look at the branch, the commit, and the files the agent created.

  4. Make it programmable

    Write run_agent.py (uv single-file script) that shells out claude -p "<the same agentic prompt>" --output-format stream-json --verbose and writes output to a file.

  5. Delete and replay

    Delete the branch and run uv run run_agent.py — verify the agent reproduces everything with zero interaction.

DONE WHEN The branch, files, commit, and final report are recreated entirely by the programmatic run — and you never typed a line of code.
LEVEL UP Write the same runner in a second language (shell or Bun) and have the agent's prompt also open a PR via gh.
