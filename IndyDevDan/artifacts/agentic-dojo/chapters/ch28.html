The Rules of the Dojo

Six rules, no exceptions.

Train on a real codebase. Not a toy — yours. Every workout below names the chapter that explains it; re-read the chapter, then do the rep. Keep a training log in your repo (a running markdown file counts) and track Dan's four KPIs weekly: Size ↑, Attempts ↓, Streak ↑, Presence ↓.

Spend tokens to save time. Optimizing your API bill instead of your hours is, in Dan's words, a failure of imagination. And every morning, the meta-question: "Am I working on the agentic layer, or the application layer?"

Four phases, rising load. Foundations → systems → custom agents → orchestration and trust.
2

Phase 1 · Weeks 1–3 — Foundations

  1. Week 1 · Feel the difference (ch02, ch03)

    TAC-1 workout: run an AI coding prompt and an agentic prompt side by side, then run an agent programmatically. TAC-2 workout: make one real codebase legible to agents — stdout, types, and a /prime command — and verify with a one-shot fix.

  2. Week 2 · Master your context window (ch10)

    AH-1 workout: cut your Claude Code boot context by more than 50%, replace always-on memory files with priming, and delegate one job to a background context window. Reduce & Delegate until it's reflex.

  3. Week 3 · First pipeline, first rebuild (ch04, ch27)

    TAC-3 workout: build a chore→plan→implement pipeline from templates and ship one chore with exactly two prompts. Repo gym: rebuild agentic-drop-zones — one file-watcher plus a drops config is your first taste of agentic infrastructure.

PHASE 1 DONE-WHENYour codebase primes in one command, your context boot is half its old size, and one chore shipped with two prompts and zero manual edits.
3

Phase 2 · Weeks 4–6 — Systems

  1. Week 4 · The prompt ladder and going AFK (ch11, ch05)

    AH-2 workout: build a seven-level prompt ladder in one repo — one prompt per level, all sharing the same section format. TAC-4 workout: ship one GitHub issue to PR with zero keyboard time between prompt and review.

  2. Week 5 · Close the loops, see everything (ch06, ch27)

    TAC-5 workout: convert your manual verification ritual into closed loops an agent runs, including one browser-level e2e test. Repo gym: rebuild the hooks-mastery meta-agent, then the multi-agent observability stack — hooks → server → SQLite → live dashboard.

  3. Week 6 · Focus and armor (ch07, ch22)

    TAC-6 workout: add review and document agents to your pipeline, with image proof and conditional docs. Then install damage control on every production repo and run the bash-security drill — attack your own guardrails.

PHASE 2 DONE-WHENAn issue became a PR while you were away, your agents validate their own work in a loop you can watch on a dashboard, and destructive commands bounce off your hooks.
4

Phase 3 · Weeks 7–9 — Custom Agents & Experts

  1. Week 7 · Parallelize, then drop the R (ch08, ch22)

    TAC-7 workout: run two ADWs in parallel via git worktrees, then take one trivial problem class to zero-touch with auto-merge. Video drill: the zero-to-skill build — author one real skill from a blank directory, cookbook and all.

  2. Week 8 · Build agents, ditch the middleman (ch12, ch27)

    AH-3 workout: build three custom agents of increasing capability on the Claude Agent SDK — a Pong agent, a tool-wielding Echo agent, and a read-only codebase QA agent with a security hook. Repo gym: rebuild beyond-mcp and measure the same toolset four ways (MCP vs CLI vs scripts vs skill).

  3. Week 9 · Experts and your own layer (ch14, ch09)

    AH-5 workout: stand up one complete agent expert — Act, Learn, Reuse — for a real domain in your codebase, e.g. your database layer. TAC-8 workout: bootstrap a minimum viable agentic layer on your codebase and prove it with one gateway run and one chained ADW.

PHASE 3 DONE-WHENA custom agent you wrote answers questions about your codebase with tools you chose, an expertise file is maintaining itself, and your repo has a living agentic layer directory.
5

Phase 4 · Weeks 10–12 — Orchestration & Trust

  1. Week 10 · One interface, many agents (ch13, ch16)

    AH-4 workout: build a minimum viable O-Agent — a custom agent whose only tools are create/command/status/delete over background instances, with a file-based observability trail. MA-1 workout: build the one-shot board meeting — brief in, parallel opinionated debate, memo out, under a time and budget constraint.

  2. Week 11 · Teams that ship (ch17, ch18)

    MA-2 workout: stand up a three-tier orchestrator→leads→workers team over a real small codebase, with domain locking and per-agent mental models, driven through a single chat entry point. MA-3 workout: turn the team into an N-variant generator producing brand-consistent UI pages in parallel, with validation and till-done tracking.

  3. Week 12 · The verifier, then the grade (ch19, ch15)

    MA-4 workout: run and extend the builder+verifier system — every builder turn decomposed into atomic claims and proven, including one domain verifier you write yourself. AH-6 workout: grade your codebase against the class/grade rubric and climb exactly one grade.

6

Graduation

YOU GRADUATE WHEN Three changes shipped through ADWs with zero keyboard time between prompt and review · one problem class runs at zero-touch · a verifier or reviewer agent gates your builds · an expertise file compounds without your edits · and your four KPIs have moved for three consecutive weeks.
THEN Start over at week 1 — on the next codebase. The program is a loop, not a line. That's the point.
The loop. Train, measure the KPIs, systematize what worked, extend trust — and go again, one level up.

It's not about what you can do anymore. It's about what you can teach your agents to do for you.

— IndyDevDan
