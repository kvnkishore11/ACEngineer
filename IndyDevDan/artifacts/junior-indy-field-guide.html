02 — Multimodal assimilation
Watch with two eyes

Speech gives the reasoning. Frames reveal the demonstration.

A long video will be divided into semantic chapters and inspected through transcript evidence, scene changes, visual cues, and high-resolution code moments.

The watch strategy is layered. Broad coverage finds structure; focused reruns recover code, diagrams, and deictic moments at useful resolution.
PASS 01

Transcript-first

Extract concepts, chapters, names, claims, and visual attention cues.

PASS 02

Scene-aware frames

Preserve slides, terminal states, diagrams, UI transitions, and demonstrations.

PASS 03

Cue frames

Force captures exactly where the speaker directs attention to the screen.

PASS 04

Focused replay

Re-run important regions densely and at higher resolution for code readability.

HonestyA sparse dozen-frame scan of a sixty-minute lesson is useful reconnaissance, but it is not mastery. Critical lessons receive segmented, focused visual passes.

04 — How Junior Indy thinks
The operating loop

Assimilation means asking the right questions by default.

The course becomes useful when its recurring heuristics shape planning, coding, delegation, verification, and learning without requiring a transcript lookup first.

  1. Problem class

    What repeatable class are we solving, beyond this one task?

  2. Human constraint

    Where are you still the planner, orchestrator, reviewer, or bottleneck?

  3. Core Four

    Which context, model, prompt, and tools fit this purpose?

  4. Focused unit

    Can one agent, one prompt, and one purpose own the work?

  5. Feedback loop

    What observable evidence lets the system correct itself?

  6. Out-loop path

    Can a trigger, safe environment, and review boundary remove human babysitting?

  7. Reusable learning

    What should become a prompt, skill, workflow, evaluator, or bounded expertise update?

The loop runs before the implementation. It repeatedly moves attention from the task to the system that can solve the task class.

Improve the application—and improve the system that improves the application.

06 — Evaluation
No fake expertise

A lesson is mastered only when it survives contact with new work.

Summaries establish recall. Mastery requires evidence, reproduction, critique, adaptation, verification, and original creation.

Six gates separate familiarity from expertise. Failure at any gate produces a targeted learning task, not a confidence claim.
FIDELITY

Does it match the source?

Claims link to timestamps, frames, notes, code paths, and version context.

JUDGMENT

Does it choose well?

Scenario tests probe when to use, avoid, specialize, delegate, or stay in-loop.

TRANSFER

Does it work here?

PiCanvas and other unfamiliar projects test whether the model generalizes.

BUILD

Can it reproduce behavior?

Golden paths execute the important course labs and smaller independent versions.

SAFETY

Does autonomy stay bounded?

Isolation, restricted tools, ownership, review, and verifier loops protect the work.

CREATION

Can it make something new?

Original repositories, workflows, explanations, and visual teaching prove synthesis.

GuardrailThe goal is Indy-inspired reasoning and creation, not deceptive impersonation or copied verbal style. The work should be recognizably original.

07 — Execution
Build in dependency order

First build the metabolism. Then expand the memory.

The first usable slice should already encode judgment, act, learn, and verify. The broader corpus then deepens that functioning system.

  1. Catalog and deduplicate

    Build the source manifest for course assets and the 202-video channel corpus.

  2. Deep-ingest the canonical spine

    Complete full transcript, segmented frame, code, note, and caveat passes for all 18 lessons.

  3. Reproduce the labs

    Trace prompts to runtime behavior and capture safe, repeatable golden paths.

  4. Build Junior Indy version zero

    Install the router and initial expert mental models globally through Hermes.

  5. Prove it on PiCanvas

    Use real planning, coding, review, and creation tasks as transfer evaluations.

  6. Expand through YouTube

    Ingest the public corpus by conceptual importance, preserving evolution and recency.

  7. Compound carefully

    Act, learn, verify, reuse, version, and retire stale tool-specific guidance.

The first vertical slice has a complete metabolism. Encode → act → learn → verify → improve.
ReadyThe corpus is mapped. The next meaningful action is the canonical deep-ingest and the first working Junior Indy skill—not more planning.
