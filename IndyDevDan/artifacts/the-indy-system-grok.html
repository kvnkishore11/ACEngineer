Don’t · vs · Do

😵 Breaks multi-agent

  • Fleet before closed loops
  • God-agent does everything
  • Same model “verifies” itself
  • Verifier that writes code
  • Leads that execute
  • No domain lock
  • Identical board personas
  • Open bash everywhere

🔥 Runs multi-agent

  • CPBPP solid first
  • Specialists only
  • Builder AND different verifier
  • Verifier read-only + unpromptable
  • Leads only delegate
  • Hooks enforce paths
  • Adversarial seats
  • Script-only bash policy
