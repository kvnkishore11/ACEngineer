CPBPP · run on every work unit
0  DONE-WHEN?     observable proof of success
1  CLASSIFY       chore | bug | feature | patch | …
2  LEVERAGE       can the agent see? (stdout / types / prime)
3  PLAN           fresh agent → specs/*.md + Validation Commands
4  BUILD          fresh agent → /implement → validators green
5  PROVE          plan match · tests · screenshots read back
6  CAPTURE        commit/PR · docs · score KPIs

IF FAIL → fix the SYSTEM (template/ADW/validator), not only the app
DAILY  → agentic layer or application layer?  (≥50% agentics)

Invariants (laws — never break)

1. Stop coding — agents write app code; you write the system that writes.
2. Core Four — Context · Model · Prompt · Tools, deliberate every run.
3. One·One·One — one agent, one prompt, one purpose. Fresh per phase.
4. Plan is the prompt — high-impact work is a file in specs/.
5. Closed loop — Request → Validate → Resolve. No “done” without a check.
6. Fix the system — failure upgrades templates/ADWs, not only the symptom.
7. 3× rule — three times → command/ADW immediately.
8. R&D — context only by Reduce or Delegate.
9. Own the layer — your templates on your codebase.
10. Layer filter — ≥50% time agentic. Daily question.

KPIs every run: Size↑ · Attempts↓ · Streak↑ · Presence↓

Part 1 · Universal method (any work unit)

0

Done-when gate

Write: Done when ________ (observable).

Cannot write it → STOP. You don’t have a problem yet.
1

CLASSIFY — pick exactly one class

chore mechanical · bug wrong behavior · feature new value · patch review miss · document teach agents · research explore · decision strategy brief

None fit → do once as discovery, then PROMOTE a new template (3×).
2

LEVERAGE — can a blind agent win?

stdout? types? /prime? right model/tools? If blind → chore the leverage fix first.

3

PLAN — fresh agent + class template

/chore | /bug | /feature → specs/{class}-{slug}.md with Description, Files, Steps, Validation Commands.

Vague plan → reject. Fix the template if shape is wrong.
4

BUILD — fresh agent (new session)

/implement specs/<plan>.md → all validators green → report + git diff --stat.

>3 retries → STOP. Fix system. Do not chat longer.
5

PROVE

Plan match · tests · UI screenshots read back · severities (skippable / tech_debt / blocker). Blocker → /patch → BUILD.

6

CAPTURE

Commit/PR · optional document · score KPIs.

7

PROMOTE — this grows the layer

3× → command · babysitting → ADW · re-learned domain → expert · streak → ZTE for that class only. Always change one agentic-layer file when a gap appears.

Part 2 · Bootstrap (empty → MVAL)

Exact structure. Agentic ring outside application code.

├── apps/                          # application ONLY

└── .claude/commands/
    ├── prime.md
    ├── chore.md · bug.md · feature.md
    └── implement.md               # HOP
  1. Scaffold dirs (never put agentic inside apps/src)
  2. Write prime.md → chore/bug/feature.md → implement.md
  3. Gateway adw_prompt.py, then chain adw_chore_implement.py
  4. Done-when: one real chore ships with zero hand-typed app code; plan in specs/

Part 3 · The only ladder

Climb. Do not collect options. Highest solid rung only.

R1

Prime

Add /prime + thin CLAUDE.md. Pass: agent orients without free wander. Forbidden: BFC, ADWs, MCP pile.

R2

BFC + HOP

chore/bug/feature + implement + specs/. Pass: real chore in exactly two prompts, zero hand code.

R3

Closed loop

Validation Commands + optional hooks. Pass: agent self-heals from test failure without you editing.

R4

ADW + PITER

adws/ plan→build→validate→honest log. Pass: one AFK ship. Fix templates on fail, not one-off code.

R5

Isolation

Worktrees / *_iso. Pass: two tickets parallel, main clean.

R6

Review + docs

Review gate + app_docs. Pass: ship path includes proof.

R7

Agent expert

One domain: expertise.yaml + self-improve. Pass: you never hand-edit expertise.

R8

Fleet (optional)

O-agent only after R4–R7 are boring. Pass: ≥2 agents produce files; orchestrator never codes.

~5–7 weeks to R7 at 60–90 min/day on a real repo. ADWs without R3 = vibe automation.

Part 4 · “I got work today”

Same protocol · every ticket · every day
  1. Write DONE-WHEN
  2. CLASSIFY
  3. /prime if new session
  4. PLAN via class template → specs/
  5. BUILD via /implement (or adw_*.py if R4+)
  6. PROVE
  7. CAPTURE
  8. PROMOTE one layer file if anything hurt

You do not open the IDE and “just fix it.” You run the method. The method produces the fix.
