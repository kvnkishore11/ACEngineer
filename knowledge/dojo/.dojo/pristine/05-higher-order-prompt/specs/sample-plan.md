# Chore: add a greet CLI to the dojo playground

## Chore description
The playground needs a tiny `greet.py` command-line script so we have a runnable artifact to point validation at. This plan was generated by a `/chore`-style meta prompt; a fresh agent running `/implement specs/sample-plan.md` makes it real.

## Relevant files
- `greet.py` — new file, created by this plan (lives next to `specs/`)
- `specs/sample-plan.md` — this plan; read top to bottom before executing

## Step-by-step tasks
1. Create `greet.py` with a function `greet(name: str) -> str` that returns `Hello, <name> — welcome to the dojo.`
2. Add a `__main__` block: take an optional first CLI argument (default `sensei`) and print `greet(<arg>)` to stdout — stdout is a leverage point.
3. Add a one-line module docstring at the top of `greet.py` describing what the file does.

## Validation commands
- `python3 greet.py` — prints `Hello, sensei — welcome to the dojo.`
- `python3 -c "from greet import greet; assert greet('Dan').startswith('Hello, Dan')"` — the function imports and behaves
