# local-visual-plan

Work on the `/local-visual-plan` Claude skill — turning a text plan into a
single self-contained interactive HTML plan locally, with no hosted-engine
dependency.

**This project is not part of the IndyDevDan archive.** It shares a repository
with it and nothing else. Nothing here describes a lesson, a codebase, or a
video.

## Layout

| Path | What it is |
|---|---|
| `MISSION.md` | What the project is trying to achieve. |
| `NOTES.md` | Working notes. |
| `RESOURCES.md` | External references. |
| `plans/` | Rendered plan HTML. |
| `lessons/` | Rendered lesson HTML. |
| `learning-records/` | Records of what was learned from each iteration. |
| `reference/` | Reference HTML. |
| `onboarding.html` | The onboarding walkthrough (was `docs/guides/local-visual-plan-onboarding.html`). |

## Issues

Issues and PRDs for this project live at **`.scratch/local-visual-plan/`**, not
here. That is the repository-wide convention — see
[`docs/agents/issue-tracker.md`](../../docs/agents/issue-tracker.md), which
defines `.scratch/<feature-slug>/` as the tracker location. It stays where it is.
