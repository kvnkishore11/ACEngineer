# Product Overview — Meridian AI

## What We Are
Meridian AI is an enterprise AI deployment infrastructure company. We provide the tooling and platform for large organizations to run large language models (LLMs) and AI workloads entirely on their own infrastructure — on-premise data centers, private cloud, or air-gapped environments — with full data sovereignty and zero external dependencies.

## Core Product
- **Meridian Deploy:** Containerized LLM serving platform — deploy any open-weight model (Llama, Mistral, Qwen, etc.) on customer hardware with automatic GPU optimization, load balancing, and model versioning
- **Meridian Guard:** Enterprise guardrails and policy engine — content filtering, PII detection, usage auditing, and compliance logging that runs entirely on-premise
- **Meridian Train:** Fine-tuning and RLHF infrastructure for on-premise model customization using customer data that never leaves their network
- **Meridian Observe:** Monitoring, cost tracking, and performance benchmarking for on-premise AI workloads

## Core Differentiator
True air-gapped deployment. Competitors require cloud connectivity for licensing, telemetry, or model updates. Meridian runs fully disconnected — no phone-home, no license server, no external dependencies. This is why defense contractors, regulated financial institutions, and now sovereign governments want us.

## Key IP
- Zero-dependency GPU optimization engine: automatically tunes model inference for customer's specific hardware (NVIDIA H100, A100, L40S, AMD MI300X) without cloud lookup
- On-premise RLHF pipeline: full reinforcement learning from human feedback loop running locally — no data leaves the network, ever
- Multi-model orchestration: route queries across multiple on-premise models based on task complexity, cost, and latency requirements
- 2 patents filed: air-gapped model update protocol, hardware-adaptive inference optimization
